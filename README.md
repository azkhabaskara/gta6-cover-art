Neon Shore Cover Studio — an offline web app that turns your photo and a caption into GTA-style poster cover art: multi-panel layouts, per-panel crop and position, Vice City sunset and neon colour grades, bold Anton title lettering with a Pacifico script subtitle, and PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos are read on your own machine and never uploaded. All art, lettering and fonts are original (Anton and Pacifico under the SIL Open Font License); no Rockstar Games logo, artwork or font is used.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Pick Photo A and Photo B (or load the bundled samples), choose a layout and a grade, drag each photo to position it, edit the title, and hit Export PNG.
